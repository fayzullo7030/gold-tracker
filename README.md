# Gold Tracker PWA

Мини-приложение для отслеживания цены 5-граммового золотого слитка ЦБ Узбекистана.

Сохраняет локально:
- цену продажи;
- обратный выкуп в неповреждённой упаковке;
- спред;
- дату и время;
- историю и график.

Источник: https://cbu.uz/ru/banknotes-coins/gold-bars/prices/

## Важное ограничение

PWA не может гарантированно выполнять JavaScript ровно в 09:30, когда приложение закрыто: Android/browser ограничивает фоновые задачи.

Текущая версия делает проверку при открытии приложения и, если за текущую дату ещё нет записи, автоматически пытается получить данные.

Кроме того, прямой `fetch()` с браузера может быть заблокирован политикой CORS, если сайт ЦБ не разрешает запросы с другого origin. В таком случае потребуется очень маленький публичный прокси/edge-function; база данных при этом всё равно не нужна.

## Размещение

PWA должна открываться по HTTPS (например, GitHub Pages, Cloudflare Pages или другом статическом хостинге).

После размещения откройте сайт на Android → меню браузера → «Добавить на главный экран / Установить приложение».
